## 1. LinkedIn Algorithm: How Profiles Are Ranked in Search

### Ranking Factors (by weight)

| # | Factor | Weight | How It Works |
|---|--------|--------|-------------|
| 1 | **Keyword match in headline + title** | Highest | LinkedIn looks for exact match with the recruiter's search query |
| 2 | **Profile completeness (All-Star)** | Very high | All-Star = 40x more frequent in search results |
| 3 | **Network proximity** | High | 1st connections > 2nd > 3rd. More connections = more "coverage" |
| 4 | **#OpenToWork** | High | LinkedIn explicitly confirms: "we'll help your profile show up in search results" |
| 5 | **Engagement / Activity** | Medium | Active profiles rank higher than "dormant" ones |
| 6 | **Skills match** | Medium | Recruiters filter by standardized skills |
| 7 | **InMail response rate** | Medium | Responsive profiles rank higher |

### Indexed Fields (confirmed)

1. **Headline** (highest priority)
2. **Job Title** in Experience (also high)
3. **About/Summary** (fully indexed)
4. **Experience descriptions** (all text)
5. **Skills section**
6. **Recommendations text**
7. **Media descriptions and captions**
8. **Published content** (articles/posts)

## 2. Experience: How to Write Descriptions

### Character Limits

| Field | Limit | Visible without clicking |
|-------|-------|--------------------------|
| Headline | 220 characters | ~60-70 characters |
| About | 2,600 characters | ~200-300 characters |
| Experience description | 2,000 characters | ~3 lines |
| Experience title | 100 characters | Fully |

### Description Format

- **5-7 bullets per role** (up to 10 for current)
- **First 2-3 bullets = most important** (recruiters scan)
- **XYZ formula:** "Accomplished X, measured by Y, by doing Z"
- **Quantify everything:** RPS, MAU, uptime, team size, % improvement
- **Action verbs:** built, designed, scaled, reduced, led, optimized
- **Keywords in the first bullets of each role**

### Keywords Placement

```
Headline (max weight) → About (first 3 lines) → Experience title → Experience bullets → Skills
```

Natural repetition of target keywords 3-5 times across different sections. LinkedIn does not have a formal keyword density metric, but repetition strengthens relevance score.

## 3. Skills: Strategy

### Quantity and Priorities

- LinkedIn allows up to **100 skills**
- Only **top 3 skills** are visible on the profile by default
- Recommendation: add **30-50 relevant skills**, carefully choose the top 3
- **Hard skills > soft skills** for recruiter search (Go, Kubernetes, not "Leadership")

### Endorsements

- **5+ endorsements per skill = 33x more recruiter contacts** [cultivatedculture.com]
- Endorsed skills rank higher
- Endorsements from people in the same industry carry more weight
- Even unendorsed skills are indexed for search

### Skill Assessments

- Top 30% = visible badge
- Free, adds credibility
- Available for Go, Python, REST APIs, Git, Linux, and more
- LinkedIn: "signals to recruiters that you've taken initiative to show skill proficiency"

### Recommended Top 3

1. **Go (Programming Language)** — primary stack
2. **Distributed Systems** — senior signal
3. **AI Agents** — trending differentiator

## 4. How Recruiters Search on LinkedIn

### LinkedIn Recruiter Filters

- **Keywords** (free text — searches across all fields)
- **Location** (city/country + 100-mile radius)
- **Workplace type** (Remote / Hybrid / Onsite)
- **Skills** (standardized LinkedIn skills)
- **Years of experience**
- **Current / Past company**
- **Open to Work** status
- **"Must have" / "Can have" / "Doesn't have"** qualifiers on each filter

### Boolean Search (supported by LinkedIn)

```
"senior backend engineer" AND (Go OR Golang OR Rust)
"software engineer" AND "distributed systems" NOT junior
"backend" AND ("AI agents" OR "machine learning") AND Go
```

Operators: **AND, OR, NOT** (CAPS required), quotes for exact phrases, parentheses for grouping. Wildcards are NOT supported.

[Source: linkedin.com/help/linkedin/answer/a524335]

### Typical Recruiter Behavior

- 87% of recruiters use LinkedIn [waalaxy]
- **6-7 seconds** per profile view
- They look at: photo → headline → current position → experience (top 2-3 roles)
- 7 people get hired through LinkedIn every minute
- 9,000 job applications every minute

## 6. Engagement: What Actually Works

### Comments > Likes > Posts

| Action | Impact on Visibility |
|--------|---------------------|
| **Comment of 15+ words** | 2.5x boost to post reach + profile visibility in others' networks |
| **10-20 comments/day** | +50% profile views |
| **Likes** | Minimal impact |
| **Posts** | Good for branding, less for direct search ranking |
| **Groups** | Dead in 2025, don't waste time |

### Content Strategy for Job Search

- **2-3 posts/week** — consistency matters more than volume
- **Best time:** Tue-Thu, 8-10 AM in the target audience's timezone
- **What works:** technical deep-dives, "what I learned building X", open source announcements
- **What does NOT work:** motivational quotes, engagement bait, reposted memes
- **Posts > Articles** for visibility. Articles for credibility + Google SEO

### Commenting Strategy

- Comment on posts by hiring managers and CTOs at target companies
- 15+ words, substantive (LinkedIn actively penalizes generic/AI comments)
- This is the most effective way to get noticed without posting

## 7. Connections: Strategy

- **500+ = credibility threshold.** Below that, the exact number is shown (looks "small")
- Above 500 — "500+", standard
- **Personalized requests** = +15% acceptance rate
- **Recently promoted execs** = 4x more responsive to connection requests
- **Quality > quantity** after 500: connect with Go/AI engineers, hiring managers, CTOs

## 9. Recommendations & Endorsements

### Recommendations

- **14x more profile views** with recommendations
- **3-5 recommendations** = optimum
- Priority: from managers > peers > reports
- Used as tie-breaker between candidates
- Recommendation text is indexed (adds keyword-rich content)

### Endorsements

- **5+ per key skill = 33x more recruiter contacts**
- Ask for endorsements on Go, Distributed Systems, AI Agents
- Endorsements from people in the crypto/AI industry carry more weight
